# React Bits

The Aurora GLSL shaders and OKLCH color conversion used in `src/visual` are
adapted from React Bits by David Haz (Copyright © 2026).

Source revision: `e12c22192ac7b4b452c5e2feb9b586d74765d696`

Source: https://github.com/DavidHDev/react-bits/blob/e12c22192ac7b4b452c5e2feb9b586d74765d696/src/ts-default/Backgrounds/Aurora/Aurora.tsx

The renderer is adapted for Nebula's shared background, visibility lifecycle,
frame-rate limit, and static fallback. The Spotlight surface is a local CSS
implementation inspired by https://reactbits.dev/components/spotlight-card.

React Bits' MIT + Commons Clause license is included verbatim at
`public/react-bits-license.txt` and distributed with the built application at
`/react-bits-license.txt`. It applies to the adapted React Bits code.
